# Credit Card Fraud Detection 

## Overview
Built a fraud detection model using machine learning to identify fraudulent transactions.

## Dataset
Download the dataset from Kaggle:
https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

## What I did
- Handled class imbalance using SMOTE
- Trained Logistic Regression, Decision Tree, Random Forest
- Achieved 99.99% accuracy with zero missed frauds

## Libraries
pandas, numpy, sklearn, imbalanced-learn, plotly

## Results
| Model | Accuracy |
|---|---|
| Logistic Regression | 88.92% |
| Decision Tree |99.84% |
| Random Forest | 99.99% |

## Key Findings
- V14, V10, V12 are top fraud predictors
- Zero false negatives — no real fraud missed
- Only 11 false
